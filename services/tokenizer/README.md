# Tokenizer service

Обеспечивает возможность токенизации текста.

Внешний интерфейс обеспечивает фреймворк userver.

Схема запросов:
1. POST /tokenize

	Перевести текст в токены

	Тело запроса:
	```js
	"text to tokenize"
	```

	Тело ответа:
	```js
	[ 1, 2, 3, ...] // Токены
	```

2. POST /detokenize

	Перевести токены в текст

	Тело запроса:
	```js
	[ 1, 2, 3, ...] // Токены
	```

	Тело ответа:
	```js
	"text to tokenize"
	```
