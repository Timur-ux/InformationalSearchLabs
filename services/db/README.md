# db service

Сервис с БД проекта.

Обеспечивает работу с сохранённым прямым и обратным индексом страниц

Действия:

1. Добавить ключ и набор значений в таблицу
2. Выбрать все пары с заданным ключом / ключами из таблицы

Таблицы:

1. Прямой индекс (ключ: id документа, значения: id токенов в порядке добавления)
2. Обратный индекс (ключ: id токена, значения: id документов в отсортированном порядке)


## Доступ к сервису

Доступ к сервису обеспечивается запросами по сети по схеме CRUD. Сетевой фреймворк для обработки запросов -- userver

Описание запросов:

1. POST /insert

	id -- id документа

	Вставить в таблицу с прямым индексом токены документа, а в таблице с обратным индексом ко всем токенам документа добавить новый документ

	В теле запроса передаются json сериализованный id документв и массив из id токенов:
	```js
	{
		"id": id,
		"tokens": [ 1, 2, 3, ... ]
	}
	```

	Возвращает:
	```js
	{
		"message" : string
	}
	```
	message == "success", когда вставка прошла успешно

2. GET /token?id={id}

	id -- id документа

	Найти все токены переданных документов

	Возвращает:
	```js
	[ 
		{
			"documentId" : id,
			"tokenIds" : [ 1, 2, 3, ... ]
		}, ...
	]
	```

3. GET /document?id={id}

	id -- id токенов

	Найти все документы, в которых встречается переданные токены

	Параметры запроса -- id токенов, документы которых надо найти

	Возвращает:

	```js
		[ 
			{
				"tokenId" : id,
				"documentIds" : [ 1, 2, 3, ... ]
			}, ...
		]
	```
