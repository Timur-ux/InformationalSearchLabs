# indexer service

Сервис обеспечивает индексацию страниц и сохранение индекса в БД.

## Принцип работы

Робот обкачивает интернет и сохраняет страницы в mongoDB, для каждой сохраненной страницы он посылает запрос в этот сервис с id страницы.

Дальше индексатор скачивает с mongoDB страницу, строит её индекс(т.е. превращает в последовательность токенов) и сохраняет индекс в сервисе БД.

## Схема запросов

1. POST /doIndex

Тело запроса содержит id страницы
```js
{
	"pageId": int
}
```

Тело ответа:

```js
"sussess"
```
Если все прошло успешно
