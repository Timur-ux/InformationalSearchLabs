\section{Архитектурное решение}

Я решил разделить проект на отдельные компоненты, которые реализуют следующие функции, необходимые для поиска:

\begin{enumerate}
\item Обкачка интернета
\item Индексация страниц
\item Токенизация текста
\item Хранение индекса(прямого и обратного)
\item Поиск по индексу
\item Обработка поисковых запросов
\end{enumerate}

Для этого я выделил следующие компоненты:
\begin{enumerate}
\item База данных

	Хранение индекса и поиск по нему
\item Токенизатор

	Разбиение текста на токены и сборка из токенов текста
\item Индексатор

	Индексация страниц, т.е. их токенизация и сохранение в БД
\item Поисковик
	
	Поиск страниц, подходящий под поисковый запрос

\item Хранение сырых документов документов 
\item Обкатчик новостных сайтов
\end{enumerate}


Для деплоя проекта я решил использовать технологию docker, т.к. это удобно.
